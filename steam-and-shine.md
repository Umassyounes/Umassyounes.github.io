# Steam & Shine – Dry Cleaning Management Platform
## Information Technology Project

**Tools:** Node.js, Express.js, SQLite, EJS Templates, HTML/CSS  
**Role:** Full-stack development, database design, front-end forms, and project documentation  
**Skills:** CRUD operations, SQL data modeling, routing, UI form creation, server-side rendering

**Description:**  
Steam & Shine is a platform designed for a dry cleaning and wash service business (WDS). 
The system allows staff to enter customer information, create orders, select services, and calculate prices. 

I built the platform using Node.js with Express for the server logic and SQLite for data storage. 
EJS templates were used to display dynamic HTML pages such as:

- Customer information page  
- Services and pricing  
- Order placement page  
- Customer list and item list  
- Dropdown menus auto-filled from the database  

This project strengthened my understanding of full-stack development, server routing, SQL integration, 
and building practical business applications.
