# Campus Connect – UMass Boston Marketplace
## Capstone Project (Fall 2025)

**Tools:** Next.js 15, React 19, TypeScript, Prisma ORM, SQLite, TailwindCSS  
**Role:** Backend development, database schema creation, documentation, GitHub workflow  
**Skills:** API routing, data modeling, UI/UX collaboration, debugging, teamwork

**Description:**  
Campus Connect is a full-stack platform that allows UMass Boston students and staff to buy and sell items through a secure online marketplace. I worked on database schema design using Prisma ORM, backend API endpoints, seeding scripts, and version control. This project strengthened my understanding of full-stack development and collaborative workflows.
