# AWS Cloud Labs – IT 456 & IT 460
## Cloud Information Management + Cloud Integration Methodologies

**Tools:** AWS EC2, VPC, IAM, Load Balancers, Auto Scaling Groups, CloudWatch, Kinesis, Lambda, Secrets Manager  
**Skills:** Cloud architecture, secure configuration, automation, monitoring, troubleshooting

**Description:**  
Throughout IT 456 and IT 460, I completed multiple AWS hands-on labs that focused on building, securing, 
and deploying cloud infrastructure. These labs helped me practice real-world cloud engineering and 
security skills, including:

### ● EC2 Deployment and Server Configuration  
Created and configured Linux EC2 instances, attached security groups, set up key pairs, 
and connected via SSH. Practiced cloud-based server administration.

### ● VPC Networking & Security  
Built isolated VPCs with public and private subnets, NAT gateways, internet gateways, and 
custom route tables. Strengthened my understanding of cloud network architecture.

### ● Load Balancing & Auto Scaling  
Configured an Application Load Balancer (ALB), created Auto Scaling Groups, defined 
launch templates, and tested dynamic scaling in response to traffic.

### ● CloudWatch Monitoring & Alerts  
Set alarms, monitored instance metrics, and tested automated scaling and notifications.

### ● Serverless Functions (Lambda)  
Built Lambda functions and connected them to AWS Secrets Manager to securely retrieve 
sensitive values.

### ● Kinesis Data Streams  
Configured producers and consumers to process continuous data streams.

These labs helped me gain confidence working in cloud environments and applying security principles. 
I learned how cloud systems scale, how traffic moves through AWS networks, and how to troubleshoot 
real infrastructure issues.
